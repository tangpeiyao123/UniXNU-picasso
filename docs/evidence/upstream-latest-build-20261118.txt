## RED FLAG that must be read before claiming "latest"

kernel_sha256 = 452f80e206c0612329047aedecba97f0a4155a58d8c5ba2877eb190510e0e725
That is BYTE-IDENTICAL to the kernel inside the 2026-11-12 artifact (d627aa63).
Step 4 of the job is "Check iPhone X inputs and retained kernel backend" and step 6
"Prepare the isolated upstream source", so the kernel backend may be retained rather
than rebuilt from this branch. Steps 18/19 did build "signed audio, NativeGL and
runtime UI inputs" and the media payload, which is where the userspace graphics and
audio pieces would come from.

So this image pair is matched and current in its payload, but the KERNEL is the same
binary as eleven-days... two-days-old artifact. Any claim that it contains PR #23's
kernel-side changes is unsupported until the kernel hash is shown to differ.
